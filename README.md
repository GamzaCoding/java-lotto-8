## 1. 프로젝트 개요
**간단한 로또 발매기를 구현한다.**
* 사용자는 구입 금액을 입력해 금액에 맞는 무작위 로또 n개를 구매한다.
* 사용자는 당첨 번호와 보너스를 입력한다.
* 로또 발매기는 최종적으로 사용자의 1~5등 당첨 여부와 수익률을 알려준다.
* 사용자가 잘못된 값을 입력하면 에러 메시지를 통해 원인을 알려준다.
* 사용자는 에러 메시지를 확인하고 다시 값을 입력한다.
---
## 2. 기능 목록
### 입력 처리
* 로또 구입 금액을 입력 받는다.
    * 1,000원 단위로 입력 받는다.
    * [예외] 숫자가 아닌 값인 경우
    * [예외] 양의 정수가 아닌 경우
    * [예외] 1,000원으로 나누어 떨어지지 않는 경우
* 당첨 번호를 입력 받는다.
    * 번호는 쉼표(,)를 기준으로 구분한다.
    * [예외] 입력 양식 포멧(쉽표 기준)이 맞지 않는 경우
    * [예외] 숫자가 아닌 값인 경우
    * [예외] 양의 정수가 아닌 경우
    * [예외] 1~45 사이의 숫자가 아닌 경우
    * [예외] 숫자가 6개 보다 적을 경우
    * [예외] 숫자가 6개 보다 많을 경우
    * [예외] 중복된 숫자가 있을 경우
* 보너스 번호를 입력 받는다.
    * [예외] 숫자가 아닌 경우
    * [예외] 양의 정수가 아닌 경우
    * [예외] 1~45 사이의 숫자가 아닌 경우
    * [예외] 당첨 번호와 중복된 숫자일 경우

### 출력 처리
* 구매금액 입력 안내 메시지를 출력한다.
* n개 구매 메시지를 출력한다.
* 구매한 로또를 n개를 출력한다.
* 당첨번호 입력 안내 메시지를 출력한다.
* 보너스 번호 입력 안내 메시지를 출력한다.
* 당첨 통계를 출력한다.
* 총 수익률을 출력한다
### 로또 관리
* 로또를 생성한다
### 로또 생성 정책
* 1 ~ 45 사이 중복 없는 6개의 자연수를 생성한다.
* 6개의 자연수를 오름차 순으로 정렬한다.
### 로또 결과 계산
* 로또 번호 일치 갯수를 알려준다.
  * 6개 일치한다.
  * 5개 일치한다.
  * 4개 일치한다.
  * 3개 일치한다.
* 로또 당첨 등수에 맞는 금액을 계산한다.
  * 1등 당첨 경우
  * 2등 당첨 경우
  * 3등 당첨 경우
  * 4등 당첨 경우
  * 5등 당첨 경우
* 총 당첨금액을 계산한다
* 총 수익률을 계산한다.
